## Verified defects and fixes

1. **High — expired reservations admitted overlapping work.** Durable admission ignored expired active rows even while the process owner remained alive; the in-memory coordinator also released its budget on expiry. Both now retain capacity until exact-owner cleanup or durable stopped-owner recovery. Renewal still fails after expiry. A late release durably frees capacity but returns the expiry error so execution cannot be reported successful. Snapshot bytes include outstanding expired holders. Tests cover capacity denial, foreign-owner denial, live-owner recovery denial, cleanup and identity replay. Application cleanup was traced through `internal/app/resource_reservation.go`, where reservation release follows execution cleanup and renewal loss cancels the run.
2. **Medium — disabled auxiliary classifier dispatched inference.** `prepareAuxiliaryIntent` now checks model-use policy before creating a new attempt; existing durable attempts retain reconciliation behavior. Skipped classification remains skipped across admission retries. Mocked service execution verifies zero classifier calls and successful deterministic routing.
3. **Medium — built-in settings writers could lose concurrent edits.** The CLI's separate `.menu.lock` did not serialize its comparison/rename with Web writers' `.update.lock`. CLI now holds the shared lock through the existing compare, rename and sync sequence. The regression holds the Web lock, verifies CLI rejection with unchanged file bytes, then verifies success after unlock. Existing conflict and cross-process config tests also passed. External editors outside the shared lock remain outside this protocol.
4. **Medium — remote status/cancel/progress used stale CSRF grants.** Bounded grant rotation can evict the token captured when controls open. Each operation now obtains a fresh bounded grant; cancellation is never automatically replayed. Progress requests retain the follow-generation fence after grant acquisition. A real-Chrome Active Jobs fixture uses the actual browser-auth grant store, evicts eight grants before status and cancellation, and verifies one cancellation, zero denied requests and retained dialog controls. Node fixtures cover uncertain cancellation without replay and progress follow behavior.
5. **Medium — late model-use refresh overwrote saved policy.** Initially a hypothesis, confirmed by a controlled delayed-read regression. Refresh generations now fence older results and errors; toggles serialize policy mutations and disable other switches while saving. The delayed read cannot restore the pre-save switch state.

The reviewed embedded asset digest was updated for the three changed scripts. This does not deploy assets to running daemons or reload existing browser documents.
